# Roadmap Lexmentor

## MVP
- strona główna,
- katalog przedmiotów,
- baza kazusów,
- panel postępów,
- newsletter / formularz zapisu.

## Wersja 2
- logowanie,
- płatne kursy,
- generowanie pytań kontrolnych,
- ranking i grywalizacja,
- notatki użytkownika.

## Wersja 3
- integracja AI,
- plan nauki pod egzamin,
- personalizacja materiałów,
- aplikacja mobilna / PWA.
